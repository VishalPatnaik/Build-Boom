# Galaxy S24 Ultra test checklist (test APK)

Turn on **Settings → Performance diagnostics** for the FPS/frame-time readout while testing. Turn it off after.

| Area | Check | Pass |
|---|---|---|
| Install | APK installs over the previous build; opens with the Vesyron → TOWER//SHIFT intro; a tap skips it | ☐ |
| Portrait | Locked to portrait; nothing under the camera cut-out or gesture bar; no sideways scroll | ☐ |
| Touch | Tap-anywhere stacking responds instantly; buttons ≥ 44 px; no accidental double taps | ☐ |
| Campaign | Levels 1–3 play, star results, Next/Retry/Home work; map shows current level and unlock | ☐ |
| Physics | Tower sways and topples like before; heavy/gold/crystal critters behave as before | ☐ |
| Camera | Start / 10 / 30 / 60+ blocks: tower top stays in view, incoming blocks visible above the buttons | ☐ |
| Worlds | Switch worlds in the Shop: Home, Shop preview and gameplay show the same world | ☐ |
| Shop | Preview doesn't equip; level gate shows; coins and rewarded-ad routes both shown | ☐ |
| Ads | Rewarded ad loads (Google test ads until real IDs are set) and grants the reward once | ☐ |
| Billing | Purchase sheet opens from Google Play (needs products set up in Play Console + licence tester) | ☐ |
| Audio | Music/SFX play; mute in Settings works; audio stops when the app is backgrounded | ☐ |
| Haptics | Landing / perfect / boom vibrations; Settings toggle turns them off | ☐ |
| FPS | Diagnostics: gameplay average ≥ 55 FPS, long frames near 0 over 1 minute (write down actual values) | ☐ |
| Battery | 15 min of play at 50 % brightness: note battery % used | ☐ |
| Temperature | Back of phone after 15 min: warm is OK, hot isn't; note any throttling (FPS drop over time) | ☐ |
| Pause/resume | Pause mid-run, resume: no jump, no lost life | ☐ |
| Background | Home button mid-run, return after 1 min: game paused, no crash, audio resumes | ☐ |
| Save | Force-close and reopen: coins, levels, equipped cosmetics, settings all kept | ☐ |
